计时与按压
Python 界面线程曾使释放延迟约 64ms，现由独立进程负责按下、计时与释放。
100 次含后台计算的无输入基准：计时偏差中位数 0.0003ms，99 分位 0.2569ms，最大 0.4054ms。
这不包含 Windows 实际输入投递延迟，实跳仍可能有数毫秒的系统调度偏差。

非目标前台窗口拒绝输入及进程退出回收检查通过。
